# TrustTunnel NAVQS

[English](README.md) · Русский

TrustTunnel NAVQS — неофициальный форк [TrustTunnel Flutter Client](https://github.com/TrustTunnel/TrustTunnelFlutterClient) для Android. Он подключается к собственным серверам TrustTunnel.

**[APK для Android и описание выпусков](https://github.com/cyberspinex/TrustTunnelFlutterClient/releases)**

## Чем NAVQS отличается от оригинала

1. **Ночная тема.** Можно выбрать светлую или тёмную тему либо следовать системной настройке Android.
2. **App VPN — маршрутизация по приложениям.** Через VPN идут только выбранные приложения либо выбранные приложения обходят VPN. Функция ещё проходит испытания на устройствах Android.
3. **Плитка быстрых настроек.** Подключиться к серверу TrustTunnel по умолчанию и отключиться можно из панели быстрых настроек Android, даже когда приложение закрыто.

## Скачивание и установка

Когда появится публичная сборка, скачай файл `.apk` из раздела **Assets** на странице выпуска. В описании выпуска указаны доступные функции, поддерживаемые архитектуры и известные ограничения.

Чтобы пользоваться плиткой, сначала настрой сервер по умолчанию в NAVQS и выдай разрешение Android на VPN, когда система его запросит. Затем открой редактирование панели быстрых настроек и добавь плитку TrustTunnel NAVQS.
